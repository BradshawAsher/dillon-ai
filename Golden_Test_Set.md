The Golden Test Set: The pipeline will be continually evaluated against a dedicated baseline test set consisting of 30 complete transaction packets:
15 Happy-Path packets (pristine, standard financial structures).
7 Messy packets (scanned PDFs, poor contrast ratios, or inconsistent row labels).
5 Edge-Case packets (containing complex owner add-backs, deep margin declines, or working capital traps).
3 Red-Team packets (deliberately engineered with conflicting numbers, mislabeled rows, and unvouched claims).
Performance Benchmarks: To move from staging to production deployment, the agent must systematically meet or exceed these operational thresholds:
Document Classification Accuracy: ≥ 85%
Source-Backed Finding/Citation Rate: ≥ 90%
Critical Issue Recall (Catching real deal-breakers): ≥ 80%
Arithmetic Calculation Validation Pass Rate: 100% (Zero tolerance for mathematical hallucinations).
Human Reviewer Acceptance Rate: ≥ 70%
